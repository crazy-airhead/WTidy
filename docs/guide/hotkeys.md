# 快捷键

WTidy 提供两类全局快捷键：**固定方向组合**开箱即用，**每区域自定义快捷键**把常用落点一键直达。

## 固定方向快捷键

作用于最前面的窗口，默认开启：

| 动作 | 快捷键 | 动作 | 快捷键 |
|---|---|---|---|
| 左 / 右半屏 | `⌥⌘←` / `⌥⌘→` | 左 / 中 / 右 1/3 | `⌥⌘[` / `⌥⌘\` / `⌥⌘]` |
| 上 / 下半屏 | `⌃⌥⌘↑` / `⌃⌥⌘↓` | 左 / 右 2/3 | `⌃⌥⌘[` / `⌃⌥⌘]` |
| 最大化 | `⌃⌥⌘F` | 居中（保持尺寸） | `⌃⌥⌘C` |

> 个别应用不发出拖拽通知（部分 Java / Electron 应用），拖拽分屏对它们无效——固定快捷键正好覆盖这个缺口。

## 每区域快捷键

为某个布局的**指定区域**录制快捷键后，按下即把前台窗口直接吸到该区域，跳过图标条：

1. 打开 **设置 → 布局**，找到目标布局行
2. 点击行内的「录制」，按下想用的组合（需含修饰键 `⌃⌥⌘⇧`）
3. 按 `Esc` 取消录制；录错了点 `✕` 或按 `⌫` 清除
4. 同一布局的多个区域可分别录制，如「左半屏 = ⌃⌥⌘L、右半屏 = ⌃⌥⌘R」

## 冲突拦截

录制时若组合已被占用（固定动作、其他布局的区域快捷键），会弹出冲突提示并显示占用者名称，换个组合即可。WTidy 自己的固定快捷键与所有区域快捷键都不会被静默覆盖。

## 快捷键不生效？

- 检查组合是否被其他应用的全局快捷键占用（如输入法、截图工具）
- 区域快捷键随布局删除一并失效
- 仍不工作请看[常见问题](faq.md)与日志 `~/Library/Logs/WTidy.log`
