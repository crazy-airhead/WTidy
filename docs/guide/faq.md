# 常见问题

## 拖动窗口时布局图标条没有出现？

按顺序检查：

1. **辅助功能授权**：菜单栏图标若为 ⚠️ 闪烁状态说明缺权限，去 **系统设置 → 隐私与安全性 → 辅助功能** 授权（或设置「行为」页点「去授权」）
2. **⌥ 键模式**：设置「行为」页若选了「按住 ⌥ 显示布局图标」，普通拖动不会显示，需按住 ⌥
3. **菜单栏状态图标**被关闭时，图标条仍会正常出现——此项只影响菜单栏
4. 仍不工作请查日志：设置「关于」页点「打开日志」，或直接看 `~/Library/Logs/WTidy.log`

## 重新安装 / 更新后又要重新授权？

WTidy 为 ad-hoc 签名，每次构建签名都不同，macOS 将其视为新应用。在辅助功能列表中**先移除旧条目，再重新添加**即可。

## 与 macOS 自带的分屏冲突吗？

可共存：WTidy 由顶部布局图标条触发，macOS 15+ 原生磁贴由窗口拖到屏幕边缘触发，入口不同。嫌干扰可在 **系统设置 → 桌面与程序坞** 关闭「将窗口拖到屏幕边缘时平铺」。

## 某个应用拖动没有反应？

部分 Java / Electron 应用不发出拖拽通知，拖拽分屏对它们无效。用快捷键兜底：`⌥⌘←` / `⌥⌘→` 等[内置快捷键](hotkeys.md#内置快捷键)，或为常用区域[改录自己的组合](hotkeys.md#改录与自定义)。

## 多显示器如何工作？

- 布局可设**作用域**：所有屏幕，或仅指定显示器（如三等分只在超宽屏出现）
- 拖到哪块屏，图标条就出现在哪块屏，按该屏的可用布局工作
- 菜单栏「发送窗口到另一块屏幕」把前台窗口发往它不在的那块屏（多屏时以鼠标所在屏为目标）

## 如何开机自启？

设置窗口底部的「开机自动启动」开关（SMAppService 实现，重启后稳定生效）。

## 如何彻底卸载？

1. 菜单栏图标 → 退出 WTidy
2. 把 `WTidy.app` 移到废纸篓（登录项由系统随应用移除自动清理）
3. 残留数据（可选清理）：偏好 `~/Library/Preferences/com.allblue.wtidy.plist`、日志 `~/Library/Logs/WTidy.log`

## 支持 Intel Mac 吗？

官方发布的包为 **Apple Silicon（arm64）原生构建**，不依赖 Rosetta 2。Intel 机器可自行源码构建——`swift build` 默认按本机架构编译，详见[从源码构建](getting-started.md#_5-从源码构建-进阶)。

## 快捷键按下没反应？

组合可能被其他应用的全局快捷键占用（输入法、截图工具等），换一组或在录制时看冲突提示（会显示占用者名称）。见[快捷键 · 冲突拦截](hotkeys.md#冲突拦截)。
