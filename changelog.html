更新记录 ​

WTidy 的版本更新记录，新版本在顶部追加。版本号与 GitHub Releases 的 tag 一致。

下载请前往 最新版本。

macOS 未公证提示：应用为 ad-hoc 签名、未做 Apple 公证，首次打开若提示无法验证开发者，右键 App →「打开」，或执行 xattr -d com.apple.quarantine /Applications/WTidy.app 后再打开。

v0.1.2 · 2026-11-15 ​

  • 修复 拖动窗口偶发呼不出图标条：上一次未成型的轻微拖动不再拖累下一次（此前可能要拖得更远才触发）；前台应用忙碌导致监听瞬时断开时自动重连，无需切换窗口或等待心跳

v0.1.1 · 2026-11-13 ​

  • 新增 内置布局自带区域快捷键：8 个内置布局的每个区域都预置了 ⌥⌘ 加一键的默认组合，在布局列表里可见、可改录、可清除；已有的布局列表升级后自动补上
  • 优化 快捷键更短：上下半屏、左 2/3 / 右 1/3、最大化由三修饰键改为 ⌥⌘↑/↓、⌥⌘; / ⌥⌘'、⌥⌘F；原固定方向快捷键并入内置布局，可自由改录
  • 修复 布局列表行尾的清除钮不再贴着或被滚动条遮挡；设置页不再能左右晃动
  • 移除 「自动分组相邻互补布局」开关：布局本身已是多区域一体设计，不再需要把相邻布局合并成一个图标

v0.1.0 · 2026-11-13 ​

首个发布版本。原生重制的 macOS 窗口分屏工具，致敬 Window Tidy（Light Pillar, 2011–2017）。

  • 拖拽分屏：拖动窗口标题栏浮现布局图标条，图标内投影瞄准 + 整屏落点预览，松手吸附；其他位置松手不打扰
  • 布局自定义：内置 8 种布局；「网格 + 区域」编辑器（如 6×6 网格区域 (2,2)-(5,5) = 居中），实时预览缩略图，作用域支持所有屏幕 / 指定显示器
  • 菜单栏：应用布局到前台窗口（迷你预览 + 中心投影选区）、恢复所有窗口位置、发送窗口到另一块屏、最近吸附记录
  • 吸附动画：平滑动画；跨屏吸附自动分三阶段（移到目标屏原点 → 调整尺寸 → 移到最终位置），避免大窗口跨屏被裁剪
  • 自动分组：相邻同网格互补布局自动合并为单图标，图标内投影选区
  • 全局快捷键：方向半屏 / 三分 / 最大化 / 居中等固定组合，另支持每区域自定义录制（行内即录 + 冲突拦截）
  • 图标条主题：墨蓝 / 石墨 / 青碧 / 紫罗兰四套配色，背景支持默认深底或桌面壁纸
  • 可靠性：看门狗自愈（事件驱动重挂 + 10 秒心跳 + 60 秒重建）、菜单栏双态图标、SMAppService 现代登录项、日志轮转、arm64 原生
  • 国际化：简体中文 / English 跟随系统语言
