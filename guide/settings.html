设置页详解 ​

点菜单栏 WTidy 图标 →「设置…」打开设置窗口，四个标签页对齐原版：布局 / 行为 / 定位 / 关于；窗口底部有「开机自动启动」开关。

布局 ​

布局列表管理 + 网格编辑器 + 每区域快捷键录制，详见布局自定义与快捷键。

行为 ​

  • ⌥ 选项按钮：二选一——「按住 ⌥ 隐藏布局图标」或「按住 ⌥ 显示布局图标」，临时让图标条让路

  • 显示菜单栏状态图标：关闭后菜单栏图标随菜单一起消失——WTidy 没有 Dock 图标，届时将无法从菜单打开设置与退出。如需恢复，在终端执行：

    bash
    defaults write com.allblue.wtidy showStatusIcon -bool true

    然后重启 WTidy（活动监视器退出进程再重新打开）。

  • 在布局图标上显示名称：图标条上叠加布局名称标注

  • 窗口未能调整尺寸时显示警告：个别应用拒绝调整尺寸时给出反馈

拖拽分屏、全局快捷键、吸附动画是常开行为，不设开关——与原版保持一致。

图标条配色 ​

四套主题任选：墨蓝 / 石墨 / 青碧 / 紫罗兰，即时生效于图标条与悬停高亮。

背景 ​

图标条背景二选一：默认背景（随配色主题的深色底）或使用桌面壁纸（抓取当前桌面壁纸 + 蒙板，与桌面融为一体）。

定位 ​

  • 排列方向：图标条横向排列或纵向排列
  • 屏幕位置：可视化屏幕预览 + 滑块微调（与排列方向联动——横向排列调上下、纵向排列调左右）
  • 尺寸：最大宽度、屏幕边距。数值为整条图标条的总宽度；单图标宽 = 可用宽度 ÷ 布局数（基准 150pt，下限 90pt）
  • 窗口间隙：贴合 / 4pt / 8pt / 12pt——贴合为窗口完全贴齐；间距让相邻窗口留出呼吸感

关于 ​

显示应用图标与版本号、日志完整路径，并提供「打开日志」按钮。

可靠性 ​

WTidy 与原版的核心差异都在看不见的地方：

  • 看门狗自愈：切换前台应用、屏幕唤醒、显示器插拔、Space 切换时事件驱动重挂监听；每 10 秒心跳校验；每 60 秒无条件重建监听链——睡眠唤醒后「拖拽失灵」从此不需要重启应用
  • 状态可见：菜单栏图标双态（🟢 正常监听 / ⚠️ 缺权限闪烁），状态行实时显示「最近吸附」，静默失效看得见
  • 现代登录项：SMAppService（BTM 原生）实现开机自启，不依赖已失效的旧机制
  • 全程日志：~/Library/Logs/WTidy.log（512KB 自动轮转），出问题可追溯
