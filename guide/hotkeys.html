快捷键 ​

WTidy 的快捷键都挂在布局的区域上：按下即把前台窗口直接吸到该区域，跳过图标条。内置布局自带一套默认快捷键，开箱即用，也可以随时改录或清除。

内置快捷键 ​

内置布局的每个区域都预置了快捷键，一律 ⌥⌘ 加一个键：

布局区域快捷键
左右半屏左 / 右⌥⌘← / ⌥⌘→
上下半屏上 / 下⌥⌘↑ / ⌥⌘↓
三等分左 / 中 / 右⌥⌘[ / ⌥⌘\ / ⌥⌘]
左 1/3 + 右 2/3左 1/3 / 右 2/3⌥⌘, / ⌥⌘.
左 2/3 + 右 1/3左 2/3 / 右 1/3⌥⌘; / ⌥⌘'
四分左上 / 右上 / 左下 / 右下⌥⌘1 / ⌥⌘2 / ⌥⌘3 / ⌥⌘4
最大化整屏⌥⌘F
居中中央区域⌥⌘M

这些快捷键显示在 设置 → 布局 各行的右侧。删除某个内置布局，它的快捷键随之失效；点「恢复内置布局」会连同默认快捷键一起恢复。

另有两个不属于任何布局的固定快捷键：

动作快捷键
居中（保持窗口尺寸）⌃⌥⌘C
恢复吸附前的位置⌃⌥⌘Z

个别应用不发出拖拽通知（部分 Java / Electron 应用），拖拽分屏对它们无效——快捷键正好覆盖这个缺口。

改录与自定义 ​

内置布局和自己新建的布局用法相同：

  1. 打开 设置 → 布局，找到目标布局行
  2. 点击区域对应的快捷键（未设置时显示「录制」），按下想用的组合
  3. 按 Esc 取消录制；点 ✕ 或按 ⌫ 清除

一个快捷键由任意个修饰键（⌃⌥⌘⇧）加一个普通键组成，按住修饰键再按普通键即可，例如 ⌥←、⌥⌘L、⌃⌥⌘L。两点限制：

  • 至少要有一个修饰键——单独一个字母会吞掉正常打字
  • 不能只有修饰键（比如只按 ⌥⌘）——系统的全局快捷键必须落在一个普通键上

冲突拦截 ​

录制时若组合已被占用（其他区域的快捷键、上面两个固定快捷键），会弹出冲突提示并显示占用者名称，换个组合即可。想把一个内置组合挪给别的区域，先清除原来的那个。

快捷键不生效？ ​

  • 检查组合是否被其他应用的全局快捷键占用（如输入法、截图工具）
  • 区域快捷键随布局删除一并失效
  • 仍不工作请看常见问题与日志 ~/Library/Logs/WTidy.log
