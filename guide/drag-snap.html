拖拽分屏与布局条 ​

拖拽分屏是 WTidy 的招牌交互，完整还原原版 Window Tidy：不用记快捷键、不用先想好布局——拖起窗口，选项自己出现。

完整流程 ​

  1. 按住任意窗口的标题栏拖动，屏幕上浮现紧凑的布局图标条（每个图标对应一种布局，默认显示 8 种内置布局）
  2. 瞄准在图标条内完成：鼠标在图标内的相对位置投影到布局区域——比如「左右半屏」图标偏左 = 左半屏、偏右 = 右半屏，单图标即可选区，鼠标行程最短
  3. 悬停图标后整屏显示落点预览：目标区域高亮，松手前就能确认落点
  4. 松手在图标上即吸附；也可把窗口移入屏内的分区高亮中精确选区
  5. 图标条之外的其他位置松手 = 正常拖拽，WTidy 完全不打扰

吸附动画 ​

窗口吸附带平滑动画（常开行为，无需设置）。

跨屏吸附自动分三阶段：先把窗口移到目标屏原点留出空间 → 调整尺寸 → 移到最终位置。大窗口直接跨屏移动时，屏幕会先裁掉超出部分，三阶段移动避免吸附途中被裁剪。

图标条的外观与位置 ​

图标条的全部呈现细节都在设置中可调：

  • 配色主题：墨蓝 / 石墨 / 青碧 / 紫罗兰四套
  • 背景：默认深色底，或跟随桌面壁纸 + 蒙板
  • 位置：横 / 纵排列，屏幕边缘位置可视化预览 + 滑块微调，最大宽度、屏幕边距、窗口间隙
  • 临时隐藏：可在「行为」页选择按住 ⌥ 隐藏或按住 ⌥ 显示图标条
