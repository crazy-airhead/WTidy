布局自定义 ​

WTidy 沿用原版 Window Tidy 的网格 + 区域模型：一个布局 = 一套网格密度 + 若干矩形区域。例如「居中」是 6×6 网格上的区域 (2,2)-(5,5)——区域坐标都是网格格子，编辑器里所见即所得。

布局网格说明
左右半屏2×1左、右两个半屏区域
上下半屏1×2上、下两个半屏区域
三等分3×1左 / 中 / 右三列

内置布局只是预置数据，可以随意改、删，也可一键恢复默认。

编辑布局 ​

设置「布局」页双击任一布局（或新增）进入编辑器：

  • 网格密度：宽 1–12 × 高 1–12 格
  • 区域：在画布上拖出矩形即为一个区域，支持多区域（如「左窄列 + 右上 + 右下」）
  • 实时预览：右侧缩略图随时显示当前布局的实际效果
  • 名称：布局名显示在图标条标注与菜单栏中

作用域 ​

每个布局可选可用屏幕：所有屏幕（默认）或仅指定某一块显示器——比如只在超宽屏上提供「三等分」，笔记本屏上不出现。对齐原版的 "All Screens" 概念。

布局列表管理 ​

「布局」页的列表支持：

  • 拖动排序——顺序即图标条中图标的顺序
  • 新增 / 删除；误删可用「恢复内置布局」找回
  • 每区域快捷键：内置布局已预置，列表行内可直接改录（详见快捷键）
