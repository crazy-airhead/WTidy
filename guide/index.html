使用指南总览 ​

WTidy 是原生重制的 macOS 窗口分屏工具（Swift + AppKit），致敬 Window Tidy（Light Pillar, 2011–2017）。它把「拖动窗口 → 浮现布局图标条 → 图标内瞄准 → 松手吸附」做为核心交互，配合布局自定义、每区域快捷键与菜单栏应用布局，覆盖日常所有分屏场景。

功能矩阵 ​

功能说明文档
拖拽分屏拖动窗口浮现布局图标条，图标内投影瞄准 + 整屏落点预览拖拽分屏与布局条
布局自定义网格 + 区域模型编辑器，内置 8 种布局，按显示器设作用域布局自定义
全局快捷键内置布局自带 ⌥⌘ 加一键的默认快捷键，每区域可改录，冲突自动拦截快捷键
设置页行为 / 定位 / 图标条主题 / 开机自启设置页详解
安装与授权下载安装、辅助功能授权、从源码构建快速开始
故障排查图标条不出现、授权失效、与系统分屏共存等常见问题

环境要求 ​

项目要求
操作系统macOS 13.0 及以上
机型Apple Silicon（arm64 原生构建，不依赖 Rosetta 2；Intel 机器可自行源码构建）
辅助功能权限必需（首次启动引导授权）
源码构建Command Line Tools 即可，无需 Xcode

设计与可靠性 ​

WTidy 与 2017 年的原版有三个核心差异：登录自启改用 SMAppService（BTM 原生），拖拽监听由看门狗守护（事件驱动重挂 + 心跳 + 周期重建），arm64 原生不再依赖 Rosetta 2。详见设置页详解 · 可靠性。
